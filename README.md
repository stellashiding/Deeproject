# DeeProject Behavior QA Prototype

A high-fidelity, customer-facing research prototype for configurable behavioral evaluation of multi-turn AI conversations.

## Run locally

Open `index.html` directly in a browser, or run a small local server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/root`.
6. Save. GitHub will provide a public prototype URL.

## Prototype features

- Normal chatbot interface with a Behavior QA toggle
- Configurable core dimensions and user-defined sub-dimensions
- Domain, evaluation goal, rubric hints, models, and evaluation frequency
- Turn-level QA timeline
- Turn inclusion/exclusion and importance marking
- Automatic or manual episode grouping
- Long-horizon session analysis
- Context drift, memory retention, consistency, goal progress, and recovery views
- Scripted responses and simulated scores for reproducible user testing

## Recommended study disclosure

Tell participants that the prototype uses scripted responses and simulated evaluation outputs. The interaction is functional, but the behavioral scores are not generated by a production evaluator.

## Suggested CHI framing

1. User-configurable behavioral evaluation
2. Flexible evaluation granularity: response, turn, episode, conversation
3. Long-horizon behavioral sensemaking
